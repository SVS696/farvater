Адреса DNS запрашиваются у DHCP-сервера выбранной сети и обновляются автоматически. Вручную переписывать IP-адреса не требуется. Здесь используется DHCP для IPv4.

DHCP должен выдавать независимый DNS. Адрес этого же DNS-профиля создаст цикл запросов.

Локальные DNS-записи

Можно вставить содержимое обычного hosts-файла: IPv4 или IPv6, пробел, одно или несколько имён. Комментарии после # допустимы. Здесь нет обращения к внешнему DNS.

После сохранения выберите этот DNS в общем правиле для указанных имён. Не назначайте его DNS по умолчанию: неизвестные имена он не разрешает. Поля маршрута и область устройств задаются в правиле.

DNS от OpenVPN

Работает после подключения VPN. Для разрешения имени самого VPN выберите независимый DNS: использовать этот же VPN нельзя.
