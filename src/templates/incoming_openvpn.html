Защита служебного обмена {% set wrap=n.get('tls',{}).get('control_wrap',{}) %}

tls-crypt скрывает служебный обмен и затрудняет распознавание OpenVPN. Он не гарантирует работу в любой сети. Общий ключ включается в клиентский .ovpn; после его изменения выдайте клиентам новые конфиги.

Направление ключа tls-auth

Используется только для tls-auth. Клиентский конфиг получает противоположное направление автоматически.
