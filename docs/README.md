# Документация Фарватера

Начните с выбора роли машины. Локальный узел обслуживает приложения через
DNS и прокси. Шлюз принимает системный или сетевой трафик и требует отдельной
административной настройки. Панель через SSH управляет уже установленным Linux-узлом.

## Установить

1. [Локальный узел: быстрый старт](../README.md#запустить-локальный-узел) — знакомство с панелью на macOS или Linux.
2. [Linux-сервер](linux.md) — зависимости, HTTPS, проверка комплекта и первая установка.
3. [macOS](macos.md) — локальный узел, автозапуск, частный SOCKS-вход и удалённая панель.
4. [Системный и LAN-шлюз macOS](macos-gateway.md) — экспериментальный режим для выделенного Mac.
5. [Совместимость](validation.md) — какие проверки выполнены и где остаются ограничения.

## Использовать

1. [Правила, применение и цепочки](usage.md) — первый маршрут и проверка трафика.

3. [Безопасность](../SECURITY.md) — административный доступ и приватные данные.
