# Документация Фарватера

## Если вы впервые видите панель

Начните с [объяснения устройства Фарватера](panel-overview.md): для чего он нужен,
как связаны разделы и какой вариант установки выбрать. Здесь не нужно знать
названия протоколов или читать исходники.

## Первый запуск

[Установить и настроить Фарватер](setup.md): подготовка компьютера, запуск,
вход в панель и подключение первого приложения.

Для отдельного сервера есть [установка Linux](linux.md), для Mac —
[настройки macOS](macos.md) и [экспериментальный системный шлюз](macos-gateway.md).
[Совместимость](validation.md) показывает ограничения текущего выпуска.

## Работа с панелью

[Выбрать раздел панели](scenario-coverage.md) — обзор, мониторинг, правила,
подключения, DNS, устройства, изменения и резервные копии.

1. [Направить трафик через другой узел](setup.md#5-подключите-вторую-машину-как-следующий-узел).
2. [Подключить приложение или устройство](panel-devices.md).
3. [Настроить правила и DNS](panel-rules-dns.md).
4. [Сохранить или восстановить настройки](panel-backups.md).
5. [Разобраться, почему не работает](troubleshooting.md).

[Удалённая панель](remote-access.md) нужна только для управления Linux-узлом с другой машины.

## Разработка

Для работы с исходниками используйте [руководство разработчика](../CONTRIBUTING.md)
и [инструкции агентам](../AGENTS.md). [Безопасность](../SECURITY.md) описывает
обращение с приватными данными.
