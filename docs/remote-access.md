# Удалённая панель: управлять Linux-узлом с другого компьютера

Этот режим нужен, когда Фарватер установлен на сервере или отдельном компьютере,
а вы хотите открывать панель на своём ноутбуке. Панель соединяется с Linux-узлом
по SSH — защищённому административному соединению — и отправляет ему команды.
Сеть и VPN продолжают работать на сервере.

Это не отправка трафика ноутбука через VPN. Чтобы приложение ноутбука использовало
выход сервера, отдельно настройте [подключение к узлу](setup.md#5-подключите-вторую-машину-как-следующий-узел).
Если панель управляет узлом на той же машине, этот раздел вам не нужен.

## Что приготовить

| Параметр | Где взять |
|---|---|
| IP или имя сервера | Адрес установленного Linux-узла, доступный с ноутбука |
| SSH-порт | У администратора сервера; обычно 22, но это нужно проверить |
| Пользователь | Учётная запись Linux с разрешённым доступом к Фарватеру |
| SSH-ключ или SSH-agent | Способ входа, который уже работает для этой учётной записи |
| Ключ хоста | Проверенный публичный ключ именно сервера; сверить через консоль/администратора |
| sudo-доступ при необходимости | Права учётной записи выполнять нужные административные действия |

SSH-ключ пользователя и ключ хоста — разные вещи: первый позволяет вам войти,
второй позволяет проверить, что вы соединяетесь с нужным сервером. Пароль входа
в панель не заменяет учётные данные SSH. Сначала [установите Linux-узел](linux.md):
форма удалённого доступа сама его не устанавливает.

## Подключиться

1. Установите окружение панели по [сетапу](setup.md#2-получите-код-и-зависимости).
2. Запустите из каталога проекта: `.venv/bin/python tools/run_panel.py --mode remote`.
   При первом запуске создайте администратора панели и укажите DNS, доступный серверу.
3. После входа откройте настройку «Подключение к сетевому ядру» через помощь.
   Прямой адрес этой формы — `/server/access`.
4. Укажите подготовленные параметры, сохраните. Сохранение меняет доступ панели,
   а не сетевую политику Linux-узла.
5. Откройте «Изменения» и «Мониторинг»: панель должна прочитать актуальный статус.
   Только после этого переходите к изменениям сети.

Неизвестный или изменившийся ключ хоста автоматически не принимается. Сверьте
его с сервером; не отключайте проверку подлинности ради входа.

## Если соединение не получилось

Проверьте доступность адреса/порта, имя пользователя, доступ к ключу и проверку
ключа хоста. Если обычный SSH-вход не работает, ошибка находится до команд Фарватера.
Если SSH работает, а управление нет, прочитайте сообщение о правах и состоянии
серверной установки. После потери ответа на меняющую команду сначала перечитайте
её состояние: повторное нажатие может повторить уже выполненное действие.
