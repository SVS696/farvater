# Совместимость и проверки

Состояние для выпуска **v0.1.0-alpha.2**. Фарватер остаётся предварительным выпуском.

| Режим | Проверенная среда | Подтверждено |
|---|---|---|
| Полный Linux-сервер | Ubuntu 24.04 amd64, systemd | Чистая установка, вход по HTTPS, отдельное восстановление, DNS, SOCKS/HTTP, автозапуск после перезагрузки |
| Локальный узел | macOS arm64, Python 3.11, sing-box 1.14.1 | Запуск ядра, DNS, прокси, цепочка через SSH к Linux |
| Системный и LAN-шлюз Mac | Проверки кода и конфигурации Darwin | Имитация системных команд и `sing-box check`; реальные TUN/PF/LAN и перезагрузка ещё не проверены |
| Автоматические тесты | Linux и macOS в GitHub Actions | Наборы приложения, установщика и переносимых инструментов |

[Текущий CI](https://github.com/SVS696/farvater/actions/workflows/tests.yml)
показывает результаты конкретных коммитов. Для alpha.2 локальный набор приложения
прошёл 1185 тестов с 45 платформенными пропусками, установщик — 14,
переносимые инструменты — 42. Эти числа относятся к этому выпуску.

## Ограничения

Linux-установщик проверяет systemd и необходимые утилиты, а не название
дистрибутива. Чистая установка Fedora, Arch, Debian и Linux arm64 пока
не подтверждена. Загрузчик имеет архивы Darwin/Linux arm64/amd64 с закреплёнными
хешами; наличие архива само по себе не подтверждает поддержку платформы.

В проверенной цепочке Mac → SSH → Linux DNS и HTTP работали. После разрыва
туннеля новые запросы отказывали без наблюдаемого прямого обхода. Это результат
одной конфигурации, а не гарантия для любой политики и всех приложений.

Для приёмки системного шлюза macOS нужен выделенный Mac с двумя физическими
интерфейсами и LAN-клиентом: проверка TUN, PF, DNS, TCP/UDP, отсутствия обхода,
отказов и восстановления после перезагрузки. До такой проверки режим экспериментальный.
Проверки физического сенсорного управления и полного сценария с экранным диктором
также пока не выполнены.

Новый входящий OpenVPN с реальным мобильным клиентом отдельно не принят. Базовый Linux-установщик не подготавливает периодический сборщик мониторинга; AWG/ocserv требуют заранее подготовленных проверенных артефактов. Наличие этих форм не означает готовность соответствующей функции после базовой установки.
