# Security

Фарватер управляет сетевыми настройками и привилегированными службами Linux.
Панель запускается на loopback или за документированным HTTPS-прокси с допуском
только административных адресов. Не открывайте локальный HTTP-порт в интернет.

1. Храните admin state, SSH-реквизиты, VPN-ключи и recovery age key вне Git.
2. Перед применением проверяйте состояние, доступ управления и срок подтверждения.
3. Храните зашифрованный архив, age key и доверенную публичную идентичность отдельно
   от сервера. Проверяйте восстановление на отдельном стенде.

Для сообщения об уязвимости используйте private vulnerability reporting этого
GitHub репозитория. Не прикладывайте ключи, пароли и приватные конфигурации к issue.
